FURBYPEDIA 2.4

Abre index.html en un navegador para usar la enciclopedia.

Novedades 2.1:
- Vista de Favoritos.
- Ordenamiento por nombre, año, era, colección y favoritos.
- Limpiar filtros.
- Progreso de colección por era.
- Respaldo y restauración en JSON de datos personales.
- Reinicio de datos personales sin borrar el catálogo.
- Corrección de la ventana de bienvenida para que no reaparezca después de cerrarla.
- Herramienta para intentar instalarla como app cuando el navegador lo permita.

Tus datos personales se guardan en localStorage del navegador. Usa el respaldo JSON para conservarlos o moverlos a otro dispositivo.
